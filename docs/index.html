THE METHOD

把优化经验，变成可执行的流程。

以 Codex 的任务核验、基线验收和实验复核流程为基础，加入多路线候选、独立评估与交叉复测。

UNDERSTAND

先弄清任务

查论文、GitHub、教程、社区与本地记录，核对算法解决什么生物学问题。

REPRODUCE

建立可信基线

检查作者或已有人工复现记录；缺少可运行基线时，先补齐最小复现。

DEFINE

明确验收标准

由科学任务确定正确性与性能指标，在实验前固定比较条件和容差。

EXPLORE

沿瓶颈提出候选

从真实运行剖析入手，覆盖四类常见优化空间，每条路线提出至少三个候选。

EVALUATE

独立评估与排序

由评估 Agent 综合证据、预期收益、正确性风险与实验成本，决定先试什么。

ITERATE

小试、交叉、沉淀

按可用资源并行小试，复测可组合方案，保留成功与失败的理由及证据。

SpatialZ：
为什么这样优化？

SpatialZ 根据已有空间切片生成新深度的细胞位置、类型与表达。我们沿着“输出到底用到了哪些计算”追踪代码，再逐层扩大验证范围。

打开六步交互讲解

从被使用的结果，反推必要计算

原版先计算全量余弦相似度，抽样却只读取少量近邻供体。供体选择独立于余弦值，因此保留原近邻规则后，可以只计算实际候选的分数。

决策：消除不被读取的计算

把数值工作，与调用开销分开

逐基因的 Python 抽样调用成为另一处负担。按原顺序准备随机数，用 C++ 执行采样，让并行完成顺序不影响随机数分配。

验收：固定中间量，逐元素比较表达

让一次优化，接得住全量任务

以层为边界交接 GPU 几何与 CPU 表达，按相邻切片对排队，逐层保存并释放内存。全量 ABCA-1 已生成 989 个新深度。

落地：分层交接、持久化与恢复

重新剖析，找到下一个瓶颈

表达采样加速后，MENDER 占小试耗时的 60%–67%。Agent 将探索转向重复准备与跨层合批，并用对照实验决定保留哪条路线。

迭代：热点改变，优化重点随之改变

一个被实验证伪的直觉

把参考描述符单独缓存，看起来可以少算一次；但三层任务的模型调用从 3 次变成 4 次。输出一致，耗时却由 46.595 s 增至 61.096 s。该方案被弃用。

由失败推导下一步

这提示准备成本值得关注。将参考片和目标层合入一次 MENDER 调用后，两组阶段对照分别为 48.495 → 18.956 s、53.440 → 20.395 s，输出一致，方案再进入完整生成复测。

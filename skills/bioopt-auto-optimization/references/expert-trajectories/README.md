# 专家优化轨迹库

## SpatialZ · 从表达瓶颈到全量流水线

1. **发现冗余。** 从作者入口追到表达合成。原版先算完整参考细胞 × 生成细胞的余弦矩阵，基因表达采样仅读筛选后的少数供体。优先减少无效计算。
2. **保持选择规则。** 作者按类型大小限制请求数，在全体参考细胞的 XY 树查近邻，再过滤同类。提前按类型建树会给部分稀有类型补入原版没有的供体。保留原供体顺序、空候选行为和逐基因抽样。
3. **拆成两项手工改动。** 只算合法候选的余弦。按原顺序预生成随机数，以 C++／OpenMP 执行逐基因的抽样和赋值。在 ABCA-1 40 µm 小试上固定描述符和种子，表达矩阵 8,756 × 1,122 逐元素相同，表达合成用时 96.107→0.139 秒。作者 MERFISH 的 A100 三例核心生成合计 157.229→39.943 秒，核对了坐标、标签、描述符和表达。
4. **扩到整套数据。** CPU 和 GPU 分工，几何完成一层就交接表达计算。用相邻切片对发任务，逐层落盘、释放中间量并记录种子。三层流式试验观察到首层表达早于下一层几何完成，且与上一实现比对精确。全量 ABCA-1 案例采用该优化路径，报告资源调度和工作量，保留计时口径。
5. **核对生产路径。** Fig. 3 的三个五切片窗口沿用作者的表达实现，仅把 MENDER worker 从 200 调为 4。Fig. 3 全量 ABCA-1 使用手工优化路径，仍按层计算 MENDER。后续批量 MENDER 属于 Agent 轨迹。

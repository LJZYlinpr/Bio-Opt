# 科学等价验收

| 输出 | 验收规则 |
|---|---|
| 坐标单位、形状、ID、基因轴、查询轴、掩膜和离散标签 | 按有意义的原序精确比较。先验证 ID 唯一及覆盖，再对齐。只对确认无语义的顺序使用稳定规范化。 |
| 固定算术与精度的数值 | 比较形状、dtype 和内容字节。浮点逐位比较保留有符号零等信息。 |
| 允许舍入差异的浮点 | 在看候选结果前规定逐字段的量纲、阈值和非有限值规则。先比较掩膜与轴，再以原版为参考计算误差。若下游用排名、阈值筛选或采样，另外比较完整稳定排名、并列组、筛选集合或抽样语义。 |
| 带格式或运行元数据的输出 | 用独立读取器比较科学字段。H5AD 检查 obs/var、坐标、X、层和掩膜。BAM 保留具科学意义的 header、标记、记录和字段。仅规范化事先列明的路径、时间戳或运行备注。 |

两次基线出现差异时先定位随机来源与设备行为，再固定配置重新比较。若研究合同允许使用数值容差或统计规则，须在独立比较前定义界限，注明证据类型。官方示例指标接近只支撑对应指标。

## 随机过程

- 标记 Python、NumPy、框架、各 CPU/CUDA 设备、子进程及库内生成器。记录全局或局部、种子、状态、调用顺序、分层边界和设备确定性配置。
- 原入口的连续随机流、显式每目标重置、固定状态恢复分别登记。每层重置的证据只覆盖该合同。
- 批量抽样验证候选集合、CDF 或同一概率规则、随机数消耗、无候选处理以及抽样结果。改变算术顺序时检查边界概率和并列。
- 并行前验证同设备重复，再对照目的设备的独立单元。核对每单元起始状态、最终状态、输出及合并顺序。训练另外核对 loss、梯度、更新参数和优化器状态。
- 分离输入随机性、运行随机性和设备非确定性。是否可交换以两次基线自比和实际状态为准。

使用独立读取器读回持久产物，保留输出签名、差异量和错误退出码。分别记录官方输出比较、基线自比、候选等价、组装 QC 和独立科学准确性。缓存需要测命中、输入或依赖变更、输出改写和验证成本。

# 空间重建输出合同

先确认任务属于原生细胞联合预测、固定查询网格表达预测，还是下游组装。三者用不同的验证边界。冻结可见实测切片和顺序、实际 z、目标深度、坐标原点/单位、ROI、基因面板和表达尺度。检查训练与预处理在实际入口使用的输入和检查点匹配。

| 路线 | 允许的目标输入和主产物 | 独立比较 |
|---|---|---|
| 原生联合预测 | 提供目标 z，方法生成点数、XY 和表达。保留每个生成层及各实测层的实际物理 z。 | 层和原始行 ID、坐标、逐层点数、行到基因的绑定、表达、实测标志和标签。另查范围、重复与非有限值。 |
| 固定网格表达 | 提供冻结 XYZ、查询 ID 与行序。空网格保留掩膜，实测层保留聚合方法、占据和计数。 | 逐层查查询 ID 唯一性和覆盖、XYZ、基因轴、行序、表达、掩膜、占据和实测/预测标志。缺 XYZ 时凭有序查询 ID、目标层/基因轴和源清单绑定坐标，单凭形状无法绑定。 |
| 拼体与读出 | 读明确验收过的原生/网格预测和冻结查询合同，分层写出体积。 | 比较持久化数据集、轴、掩膜、计数和 QC。若连统一尺度一起计算，保留原模型尺度和统一尺度的转换收据。 |

若任务是留出预测，目标真实表达不得进入拟合、预处理或缓存。原生路线的候选也不能通过读入目标真实 XY 或点数改变任务。固定网格仅使用事先声明的支持范围。实测深度偏离规则层时，保留原深度及标志。原生结果栅格化是在下游定义的新表示，保留来源与映射。

## Fig. 3 实例

三窗口 ABCA-1、CosMx、Heart 各用五张实测切片。目标层按窗口相对深度 20 µm 组织，保留实际实测 z，共 20、4、28 个生成层。共同控制的两种输出分别走自己的合同。

| 方法分组 | 固定清单 |
|---|---|
| 8 种原生联合 | SpatialZ、DeepSpatial、isoST、UniST、FEAST、sc3D、3D-Omics-Flow、MIMYR |
| 6 种固定网格 | NTF、Spateo、EncMTP、STAGE、stVGP、STADiffuser |
| 2 种共用对照 | Copy、GeometryOTLinear，两条路线各有输出 |

历史生产收据是 16 个条目、48 个方法窗口、54 个路线产物位。其中 45 个方法窗口及 51 个路线产物通过 QC，STADiffuser 的三个产物位历史状态为暂停。3DFlow 的 CPU 读出、stVGP 的 GP 解码是阶段。产物通过 QC 仅证明该任务的完整性与合同，另需作者小试证据与优化配对，才可声称复现和加速。Fig. 3 的五片全输入体用于结构分析，留出片准确性须独立评价。

例外检查：Spateo 官方 2D alignment 教程不能代表 Fig. 3 的 DeepInterpolation；FEAST 冻结端点不变量须逐实现检查；GeometryOTLinear 的每目标随机 anchor 导致传输计划不同。优先寻找实际重复的、输入不变的步骤，既有一次性拟合或查询加载不能通过人为退化基线来制造收益。

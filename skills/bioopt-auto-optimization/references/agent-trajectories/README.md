# Agent 优化轨迹库

以下案例来自 KiloCode 实验。读每条的观察、尝试、验收和结论范围，再决定是否迁移。

## SpatialZ · 从拆分缓存到批量 MENDER

- **观察与尝试。** 采样变快后，重新剖析发现 MENDER 初始化占比突出。拆开计算参考描述符与查询描述符，结果逐位一致，但总时间从 46.595 秒增到 61.096 秒。
- **改方向。** 让一个 MENDER 模型处理同一对参考片和三个目标层。在单独的配对中，MENDER 从 48.495 秒降到 18.956 秒，另一切片对也验证了收益。
- **终验。** 将批量 MENDER 与候选余弦、C++ 采样合用。V100 上十二层生成的两轮配对为 1804.282→214.889 秒和 1742.078→200.323 秒。每层用固定的种子合同，表达、XY、标签均一致。计时覆盖生成，合并写出与绘图另计。早期对照使用不同随机合同，保留为失败记录。[配对代码和收据](https://github.com/LJZYlinpr/Bio-Opt/tree/main/algorithms/SpatialZ)

## SpaGRN · 把数据传一次

- **观察与尝试。** hi-res 教程的 bivariate 任务反复序列化同一大矩阵。改用 worker 初始化时传入共享状态，每个任务只传两个基因索引，保留原统计函数和任务顺序。
- **验收与边界。** Geary 和 Moran 各 15 对逐位一致。优化版教程的 bivariate 阶段约 5.5 分钟。旧版全量 5.7 天是吞吐外推，由此得到的比值只能标为估算。[代码和比较入口](https://github.com/LJZYlinpr/Bio-Opt/tree/main/algorithms/SpaGRN)

## UniST · 修正冷启动下的线程结论

- **观察与尝试。** 早期线程测试得到约 13.6×，随后检查发现顺序与冷启动混在一起。保持输入和插值脚本固定，交错运行 2、4、8 线程并重复。
- **验收与边界。** 2→8 线程均值 6.287→5.296 秒，TIFF 的 SHA-256 完全相同。按线程资源配置的收益报告。[脚本与原始计时](https://github.com/LJZYlinpr/Bio-Opt/tree/main/algorithms/UniST)

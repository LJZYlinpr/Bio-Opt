# 已验证案例与计时范围

## SpatialZ 从热点到完整生成

1. 早期 ABCA-1 40 µm 层固定 MENDER 特征，先以原 cKDTree 的全局近邻规则得到候选，再按细胞类型过滤。保留 k、顺序、权重和每基因抽样。候选计算与 C++ 采样把表达合成从 96.107 秒降到 0.139 秒，8,756×1,122 表达逐元素一致。
2. 作者 MERFISH 三个小试在 A100 上覆盖几何、标签、MENDER 和表达，合计 157.229→39.943 秒。三份比较分别验证了 XY、类别、表达和描述符。另有更便于移植的批量抽样实现，保留稠密余弦，在固定实测查询层上 15.25→0.72 秒，表达与 NumPy 随机终态一致。
3. Kilo 剖析发现拆开缓存参考与查询描述符虽然等价，MENDER 初始化次数增加使吞吐变为 0.76×。验证同批其他切片不会改变描述符后，把同一实测端点的三个目标放入同一模型，两个端点对的 MENDER 约 2.6×。
4. Kilo 在外部 V100 用四个区间、十二层的两次配对检验组合效果。生成计时为 1804.282→214.889 秒、1742.078→200.323 秒，分别 8.40× 和 8.70×。收据核对每层坐标、标签和表达。原版每目标调用前重置 NumPy seed 42，候选各目标使用同种子。它覆盖全部生成层的计算，独立上游原版运行耗时、最终合并写盘及绘图不进入该比值。历史未固定的全局随机流与这份重置合同分开。几何 Sliced Wasserstein 投影按迭代消耗随机流，复用投影与减少迭代均应作为不同方法变体。

可定位的本地收据为论文归档 `spatialz_new/README.md`、BioOpt `experiments/round2/RESULTS.md`，以及隔离区 `optimization/OPT_LOG.md` 实验 4、5、9–12、14、17、18 与 `results/SpatialZ_opt/seeded_full{,_r2}/`。读环境与入口时优先用原始命令或日志，汇总文档仅用于定位。

## 示范与迁移

| 案例 | 可以继承的证据及其范围 |
|---|---|
| SpaGRN | hi-res 教程使用传输优化后，bivariate 约 5.5 分钟，Geary/Moran 各 15 对逐位一致。旧路径全量 5.7 天为吞吐外推。另在 Heart H2 100 µm 的 7,920 个候选上，0.518→0.0258 秒覆盖构图、筛选、评分和写表，最大误差 1.11e-15 且完整排名相同。这两个实验分别验证搬运和候选评分。 |
| UniST | 官方插值示例通过输出检查，2→8 线程在重复计时中 6.29→5.30 秒，输出 TIFF SHA-256 相同。记作线程配置比较。首次 13.6× 受冷启动影响，复测后弃用。 |
| isoST | 固定 Heart H2 检查点的单 V100 读出复用全零 batch 张量，三对中位 46.52→44.53 秒；28 层及随机边界逐位通过。双 V100 的读出扩展另计。此前 loss 和 RNG 一致仍出现梯度与参数更新差异。 |
| SpaceTracer | Visium demo 按官方流程复现，缓存回放能拒绝同路径、同长度的内容改写。干净目录重跑比较还发现 BAM 的命令路径差异，独立读回科学记录相同。收益证据覆盖缓存正确性，谱系分支及外部参考指纹另验。 |
| FEAST → 3DFlow | FEAST 复用一对实测切片的 Sinkhorn 计划，Heart H2 两目标完整工作负载 397.775→202.906 秒，一次配对，产物一致。3DFlow 在冻结生成状态上独立复用四个源切片组合的索引与进度值，Heart H2 28 层读出三对中位 0.268→0.124 秒，坐标、表达、源行 ID、目标层和基因轴相同。此迁移覆盖生产读出组件。 |
| CosMx 固定网格 | 七种已验收方法的现有预测流式组装，峰值 RSS 降 19.7%–22.9%，数组、掩膜和 QC 精确一致。计时和内存范围覆盖拼体阶段。 |

项目证据入口为 BioOpt `experiments/RESULTS.md`、`experiments/round2/RESULTS.md`、`inventory/methods.json` 与隔离区 `report/THREE_CASES.md`。执行本 Skill 时需用新任务自己的作者小试、合同与配对收据。
